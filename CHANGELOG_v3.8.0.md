# SAKA Dirgantara v3.8.0

## Fokus update
- Refresh UI/UX agar lebih clean, modern, profesional, dan lebih cepat dipakai.
- Login screen dirapikan dan dibuat lebih informatif.
- Input/form control dibuat lebih jelas dan nyaman.
- Refresh/reload data kini memakai overlay ringan tanpa mengosongkan halaman.
- Tombol refresh mendapat state loading visual.
- PWA cache version dinaikkan agar aset baru langsung terbaca.

## Perubahan utama
- Tampilan login baru dengan password toggle, prefill username terakhir, dan helper chips.
- Visual panel, tabel, toolbar, topbar, sidebar, tombol, dan form diperbarui.
- Sticky toolbar pada halaman manajemen (desktop) agar alur kerja lebih cepat.
- Soft refresh overlay agar proses reload terasa lebih halus.

## Catatan
- Tidak mengubah alur bisnis inti atau struktur permission.
- Tetap kompatibel dengan role ADMIN, PENGURUS, dan ANGGOTA.
